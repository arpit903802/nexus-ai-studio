# 🚀 NEXUS // ENTERPRISE MULTI-AI STUDIO

Nexus is an advanced, high-performance multi-modal AI studio powered by **NVIDIA NIM APIs**. It integrates state-of-the-art language models, vision intelligence, and generative imaging into a single unified web interface.

## ✨ Core Features
* **Multi-Model Intelligence:** Switch seamlessly between Llama 3.1 70B, Llama 3.2 Vision, and Mistral Large.
* **Multimodal Vision AI:** Upload images directly into the chat and ask questions or analyze visual data.
* **Nexus Image Studio:** Generate high-resolution visual artwork using Stable Diffusion 3 Medium.
* **Enterprise Security & Load Balancing:** Automatic API key rotation pool to prevent rate limits and ensure 99.9% uptime.
* **Cyberpunk Glassmorphism UI:** Built with Tailwind CSS for a sleek, mobile-native dark-mode experience.

## 🛠️ Tech Stack
* **Backend:** Python, FastAPI, Uvicorn
* **AI Engine:** NVIDIA NIM REST APIs, Stable Diffusion
* **Frontend:** HTML5, Tailwind CSS, Jinja Templates
* **Hosting:** Render Cloud (Zero-cost deployment)
